Сервисы, рабочая копия и remote main сверяются по точному SHA. Финальный реально запущенный SHA передаётся в личный Telegram с живым аудитом всех трёх процессов, non-root UID, разделения окружения, API 401 без токена и доступа с корректным токеном.

Платный bootstrap: 12 облачных текстовых HTTP-попыток и одна image generation. Локальная проверка Ollama дополнительно использовала два chat-запроса на существующем GPU. Две Responses-пробы не подтвердили runtime; первая WhatsToken-проба использовала logical ID и не засчитывается как проверка wire-маршрута. Адаптер исправлен; повтор после cap не запускался. Зарезервировано 14,336 токенов; это не восстановленный фактический usage и не денежный предел. Стоимость неизвестна; автопополнение и смена тарифов не включались.

[Обращение OpenLux](../docs/provider-support-openlux-image-size.md) описывает запрос, ожидаемый размер, исходный PNG и SHA. Оно НЕ ОТПРАВЛЕНО: подтверждённый канал поддержки учётной записи здесь не настроен. Оригинал не масштабировался для маскировки расхождения. После ответа нужен новый ограниченный live retest.

Blocked-задачи сохранены для DINOv3/HF_TOKEN, Unity/лицензии/runner, Codex Responses, image size, повторного автономного E2E и game brief. Для brief нужны игровой цикл, управление, стиль, платформы/устройства, одиночный/сетевой режим и объём первого релиза.

Результаты: assets/source, assets/catalog, reports, config и технический пример game/. Operational DB/outbox и приватные журналы остаются вне Git. Зашифрованная копия на Mac — snapshot этапа, а не непрерывный backup-сервис.
